# Filter-Blue-and-yellow-Tritanomaly-
I have successfully ported the popular color perception filter for people with tritanomaly (blue-yellow color blindness) from Android to PC. Now, this accessibility solution is available on desktop devices, helping make the digital environment more inclusive and accessible.
